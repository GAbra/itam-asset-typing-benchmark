# Результаты benchmark

[English](README.md) · **Русский**

В этом каталоге намеренно хранятся два отдельных набора экспериментов.

## 1. Исходный архивный baseline

JSON-файлы непосредственно в `benchmark-results/` относятся к первоначальному эксперименту 10K / 100K / 500K / 1M, импортированному в начальном commit `e16e158`. Они сохранены без изменений.

Verification reports содержат нулевые расхождения между движками и нулевые расхождения с метками генератора. Performance reports содержат по пять измеряемых проходов для каждого размера набора.

В исходном эксперименте не были записаны CPU, RAM, host OS, exact JVM, ограничения контейнера и точный provenance бинарника/образа. Поэтому его абсолютные скорости считаются историческими наблюдениями, а не основным воспроизводимым performance result.

Для внутренней проверки архивных файлов используйте:

```sh
python scripts/validate-results.py
```

Скрипт проверяет количества записей, checksum внутри проходов, арифметику summary и согласованность verification. Он не воспроизводит старую измерительную среду.

## 2. Контролируемый baseline v2

`baseline-v2/` — текущий эталонный performance baseline. Он создан для устранения пробела provenance исходного эксперимента.

В нём зафиксированы:

- exact Docker image ID и SHA-256 JAR;
- CPU/RAM/OS хоста и Docker/WSL metadata;
- CPU- и memory-лимиты контейнера;
- Java/JVM/GC settings;
- seed, версия ruleset, SHA-256 правил и SHA-256 входных данных;
- exact commands, прогрев, число измеряемых проходов и batch size;
- generation metadata и verification reports.

Кратко о среде: Ryzen 9 7950X, Docker Desktop/WSL2, контейнер ограничен 4 CPU и 4 GiB RAM, Eclipse Adoptium Java 21.0.12, `-Xms2g -Xmx2g -XX:+UseG1GC -XX:ActiveProcessorCount=4`, seed `20260909`, два прогрева и пять измеряемых проходов.

| Активов | HashMap + BitSet | CEL | DMN / KIE |
|--:|--:|--:|--:|
| 100 000 | 337 868 активов/с | 102 782 | 48 071 |
| 500 000 | 338 754 | 102 850 | 49 285 |
| 1 000 000 | 334 237 | 104 800 | 49 150 |

Все три verification report в baseline-v2 имеют `PASS`, `engineMismatches = 0` и `groundTruthMismatches = 0`.

Полная проверка контролируемого набора:

```sh
python scripts/validate-baseline.py
```

Ожидаемый вывод:

```text
PASS: baseline v2, 100,000 assets
PASS: baseline v2, 500,000 assets
PASS: baseline v2, 1,000,000 assets
```

## Почему сохранены оба набора

Второй эксперимент не заменяет первый и не является сравнением «до/после оптимизации». Среда исходного запуска неизвестна, поэтому различия абсолютной скорости между наборами нельзя приписывать изменениям кода.

Архивный baseline сохраняет историю. Baseline v2 является воспроизводимым эталоном с явным provenance исполняемого кода и среды.

Границы измеряемого участка, семантика correctness и ограничения валидности подробно описаны в [методике](../docs/METHODOLOGY_RU.md).

Локальные нерегламентированные запуски записываются в игнорируемый `results/local/`. Новые исследовательские эксперименты следует сохранять в отдельно именованных каталогах со своим environment record и точными командами.
