# Security policy

This repository is a research benchmark, not a supported production service.
Do not deploy it with production credentials or untrusted rules/datasets.
Run experiments with synthetic inputs and appropriate local resource limits.

Security fixes are maintained on the latest release and the main branch.
Older snapshots and Docker artifacts may contain outdated dependencies.

Report vulnerabilities privately through GitHub's **Report a vulnerability**
action on the repository's Security tab. Include the affected commit/version,
minimal synthetic reproduction and impact; do not include secrets or real data.
If private reporting is unavailable, open an issue requesting a private contact
without disclosing exploit details. No response-time guarantee is provided.

Report vulnerabilities in upstream libraries to their respective maintainers.
