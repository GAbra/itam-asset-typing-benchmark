# Зафиксированные зависимости

## Java

Целевая версия: Java 21.

В Docker используется официальный образ Maven с Eclipse Temurin 21.

## CEL

Артефакт:

```text
dev.cel:cel:0.14.0
```

Используется готовая реализация CEL для Java. В проекте выражения компилируются при создании `CelTypingEngine`, а готовые `Program` повторно используются для всех активов.

Лицензия проекта CEL-Java: Apache License 2.0.

## Apache KIE DMN

Артефакты:

```text
org.kie:kie-dmn-core:10.2.0
org.kie:kie-dmn-api:10.2.0
org.kie:kie-internal:10.2.0
```

Используется реальный `DMNRuntime`, а не собственная имитация DMN.

Лицензия Apache KIE: Apache License 2.0.

## JSON/YAML

Jackson используется только для сериализации данных и чтения канонического YAML. Он не участвует в логике сравниваемых движков.

## Почему версии закреплены

Для воспроизводимого сравнения зависимости не используют плавающие `latest`-версии. Обновление библиотек должно оформляться отдельным изменением и повторным прогоном всех тестов/замеров.
