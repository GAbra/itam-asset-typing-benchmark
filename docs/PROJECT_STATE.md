# Project state

Implemented: three execution engines from one canonical ruleset; shared feature extraction/resolution; deterministic synthetic data; differential and generator-label verification; raw source illustrations; batched benchmark; Docker and PowerShell entry points.

The archived baseline covers 10K, 100K, 500K and 1M assets with zero reported mismatches. Its original hardware/runtime environment is unknown. Read [methodology](METHODOLOGY.md) before interpreting absolute performance.

Public-repository infrastructure includes English/Russian READMEs, an MIT license, citation metadata, contributor guidance, generated figures, input/runtime provenance for new runs, regression tests and a [CI workflow](../.github/workflows/ci.yml).

For the current build status, use [GitHub Actions](https://github.com/GAbra/itam-asset-typing-benchmark/actions/workflows/ci.yml); this document does not assert a permanently passing CI state. See the [README roadmap](../README.md#research-roadmap) for unimplemented experiments.
