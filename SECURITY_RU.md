# Политика безопасности

[English](SECURITY.md) · **Русский**

Этот репозиторий является исследовательским benchmark, а не поддерживаемым production service. Не разворачивайте его с production credentials и не используйте недоверенные rules/datasets. Эксперименты следует выполнять на синтетических данных с подходящими локальными resource limits.

Security fixes поддерживаются в последнем релизе и ветке `main`. Старые snapshots и Docker artifacts могут содержать устаревшие зависимости.

Уязвимости сообщайте приватно через действие GitHub **Report a vulnerability** на вкладке Security репозитория. Укажите затронутый commit/version, минимальный синтетический reproduction и impact; не прикладывайте secrets или реальные данные.

Если private reporting недоступен, создайте issue с просьбой о приватном контакте, не раскрывая детали эксплуатации. Гарантированный срок ответа не установлен.

Уязвимости сторонних библиотек следует направлять их upstream maintainers.
